# n>7 纯计数的位运算优化

本次从 `69855f486f7381b2a4488121da544dda039e5228` 开始，优化动态转移矩阵路线中的旋转对称枚举。保持计数定义、分类、任意精度总数、CLI 和导出格式不变。

## 实现范围

- 宽高均不超过 7 时沿用原 u64 快速路径。
- `(width+1)*(height+1)<=128` 时使用带空白行列的 u128 位图。空白列阻止横向跨行连接，额外行列容纳 Euler 顶点；最大顶点位号不超过 127。
- 上述范围内，面积不超过 64 时，连通性额外使用紧凑 u64 位图，并显式屏蔽行首/行尾；8×8 因而能使用单机器字连通检查。其洞分类仍使用带空白边界的 u128 表示。
- Gray 枚举通过整数序号的 trailing_zeros 定位翻转轨道，代替逐位布尔进位。两个位图在每一次翻转中同步，包括边界条件不成立的候选。
- 半转对称的上/左触边蕴含下/右触边；四分之一转只需检查上边。减少重复边界判断。
- 位图快路径的轨道数量不超过 63，因此候选数小于 2^63；局部 u64 计数保留 checked_add，结束后转为 BigUint。DP、全局累计和 Burnside 仍使用 BigUint。
- 更大棋盘继续使用原动态回退路径，没有新增尺寸上限。这一轮没有优化该回退路径；方形 n=8、9、10 均能使用新快路径，n≥11 仍受通用路径性能限制。

## 正确性验证

- 最终 `cargo test --release --locked --offline` 与 `cargo test --locked --offline` 各 72 项通过（主程序 58、参考探针 7、CLI 7），没有忽略测试。
- 独立逐格穷举对照 2×8、8×2、2×9、9×2 半转和 4×4 四分之一转计数，不复用生产轨道构造或 Euler 公式。
- 独立背景四邻接泛洪对照 8×8、9×9、10×10、7×15 的洞分类，包含闭合边框、实心块与随机稠密形状；7×15 覆盖恰好 128 位的顶点边界。
- 紧凑连通性对照包含 63×1、1×63、2×32、4×16、8×8，覆盖位 63 和跨行风险。
- 8×8 四分之一转的全部 65,535 个非空轨道组合与逐格参考分类相符。
- 独立静态审查检查了位移边界、双位图 Gray 同步、旋转触边简化、局部计数上限与动态回退，未发现缺陷。

n=8 优化前后的全量相等是回归证据，不等同于独立算法重算的完整 n=8 正确性证明。本轮没有重跑完整 n=9，也未测试大尺寸全集导出。

## 仍存在的瓶颈

9×9 半转对称枚举有 2^41−1 个候选，约为 8×8 的 512 倍。位运算减少单个候选的处理成本，没有改变指数级候选增长；本次不声称 n=9 已能在 600 秒内完成。
