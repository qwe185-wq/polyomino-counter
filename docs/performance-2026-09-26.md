# 性能实现与验证（2026-09-26）

本次从基线 `d401f45733af463defeaf8fee0e4d15242c548f7` 在隔离分支实施，主目录、历史数据集和用户未跟踪脚本均未修改。没有运行任何 n=6。

## 算法选择

纯计数改用前沿动态规划：标签编码已处理区域在扫描线上的连通分量，关闭组件时禁止留下其他无法再连接的组件，也禁止已结束后重新开始。逐格维护 `χ=V-E+F`，终态连通时 `holes=1-χ`，保留旧背景四邻接的洞规则。

DP先计算固定板内的所有连通放置C。一个紧包围盒a×b形状在w×h板中的放置数量为`(w-a+1)(h-b+1)`，所以

```text
Fixed(n)=C(n,n)-2*C(n-1,n)+C(n-1,n-1)
```

分别应用于有洞/无洞。90°、180°旋转固定点使用紧包围盒旋转轨道枚举；Gray code每步只切换一个轨道，位扩散检验连通，用Burnside组合成one-sided计数。未把按面积的现成序列当作本项目答案，也未硬编码最终结果代替计算。

导出不能只聚合数量，使用canonical BFS：对每个扩展候选取旋转最小代表，每个轨道只保留一次，再用轨道大小1/2/4还原Fixed统计作为对照。原Fixed BFS仍可选。两者均使用带padding的位前沿、整体位移生长、位矩阵转置、欧拉洞检测、每任务局部统计及有界写通道。返回分块直接作为下一代，不再树形复制大Vec；哈希容量按代规模调整，单次insert替代contains+insert。

## 计时方法与结果

Windows x86_64，Rust 1.97.1，32逻辑处理器；Rayon设32线程，默认release可移植配置（没有强制native CPU或PGO）。旧程序与新程序均在当前机器从各自源码、相同锁文件离线构建。计数每条路线预热1次，再交替9次；导出预热1次，再3次。计数DP本身是串行状态聚合，不使用32线程枚举。

| 路线 | 内部算法中位秒 | 完整进程中位秒 |
|---|---:|---:|
| 原Fixed BFS | 0.205000 | 0.226636 |
| 新DP | 0.000570 | 0.011164 |
| 优化Fixed BFS | 0.068312 | 0.081875 |
| one-sided BFS | 0.029044 | 0.041223 |
| 原导出+ZIP9 | 0.282000 | 3.275164 |
| 新导出+ZIP9 | 0.034066 | 2.923235 |
| 新导出+ZIP1 | 0.034791 | 0.388878 |
| 新导出裸bin | 0.034475 | 0.050289 |

算法计时不包含编译、进程启动和压缩；导出算法计时包含等待写盘。完整进程由父进程Stopwatch记录，包含启动、退出、输出和压缩。DP相对原算法约360倍、完整计数CLI约20倍；同级ZIP9约1.12倍；默认ZIP1端到端约8.42倍。后三者不能混称为算法加速。

一个完整ZIP文件组的体积样本为：原ZIP9 2,603,307字节，新ZIP9 2,468,305字节，新ZIP1 3,183,249字节。默认低压缩等级以更大体积换取速度，shape集合相同。并行顺序不固定，压缩量存在波动。

DP去除了按形状总数增长的存储，canonical BFS减少了旋转方向副本；本轮没有进行可靠的峰值工作集采样，故不提供内存降低百分比，也不外推n=6耗时。

复现脚本：

```powershell
cd rust
cargo build --release --locked
./scripts/benchmark.ps1 -BaselineExe <旧版room-count.exe绝对路径>
```

脚本参数限制n≤5，保存每次输出、退出码、内部/进程时间和exe SHA-256，不删除导出的对照数据。

## 正确性证据

- 改造前先新增3项行为保护，在原实现上通过：4×4独立坐标oracle、n≤5已知计数、导出完整集合。
- CLI新默认路线和拒绝非法尺寸有真实RED（旧版2项失败），改造后GREEN。
- 非空导出目录保护有真实RED（旧版会接受该目录），新实现拒绝并保持旧数据。
- n≤4穷举独立前景/背景四邻接洪泛，对照DP所有矩形；旋转轨道同暴力子集旋转对照。
- n≤4完整形状旋转、归一化、生长、洞检测以及两种BFS导出集合通过独立坐标oracle。
- n≤5 DP、Fixed BFS、canonical BFS 的总数/洞分类以及Fixed与对称分解相同。
- 实际读取n=5旧ZIP9、新ZIP9、新ZIP1：各520,818条记录，均唯一，完整集合相同。
- CLI检查DP不静默忽略导出、压缩失败返回失败并保留bin、数据清单及重复导出拒绝。Burnside三类整数性在release也检查。

原实验DFS/Jensen在n=2、3的既有失败未被“修到通过”；这些不正确的实验实现已退出生产调用图，源码留作历史参考。新的DP不是旧Jensen补丁。

## 数据与错误处理

保留u64 LE、stride8、旋转最小代表、10M条chunk和现有ZIP条目目录。输出槽按需创建，空分类不生成文件；写盘通道有界，写入/线程/压缩失败向上返回，不伪造成功清单。ZIP成功后只清理本次新建、解析后仍位于输出根下的目录。

默认ZIP从9改为1；可显式恢复9或跳过压缩。拒绝非空输出目录，每个成功数据集有独立dataset_id。并行导出不保证记录顺序，使用旧global_index的Parquet与landmarks必须继续绑定旧数据，或对新数据重建索引。

n是必填参数；缺失/非法参数返回错误，不再默认启动6或把非法值静默钳制。实现支持上限仍为6，但本次交付没有n=6运行证据。
