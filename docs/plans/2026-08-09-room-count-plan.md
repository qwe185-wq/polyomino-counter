# room-count 实施计划

**日期**：2026-08-09
**项目**：多联骨牌房间计数

## 问题重述

在 n×n 正方形网格中（n ≤ 6），每个格子是正方形。内部边上可放置墙、门或什么都不放。墙+门围成的封闭连通区域称为房间。房间至少有一个门、内部无门、且只有一个房间。房间允许旋转与平移（One-sided），禁止翻转。

求不同房间数量对 n 的表达式。

## 等价问题

房间 = 连通格子子集（polyomino），边界全墙/门，内部全空。问题等价于统计 bounding box ≤ n×n 的 one-sided polyomino 数量。

## 算法选择

### 枚举方法：Redelmeier 生长法

不从 2^(边数) 种边状态枚举，而从 polyomino 形状出发：
1. 从单格开始，每次在边界添加一个邻居格子
2. 用 one-sided canonical form（4 旋转规范化）去重
3. 哈希集合保证每种形状只处理一次

### 去重：One-sided canonical form

对 4 个旋转（0°, 90°, 180°, 270°）各做平移规范化，取位图值最小者。翻转（镜像）不考虑 — 符合"禁止翻转"约束。

### 洞检测：Flood fill

包围矩形外扩一圈，从外部做 BFS。内部未访问的空格即洞。

### 复杂度

- 时间：O(总形状数 × 平均前沿大小 × 规范化开销)
- 空间：O(总形状数) — 哈希集合主导
- n=6 时预计 ~百万级形状，运行时间 < 1 分钟
