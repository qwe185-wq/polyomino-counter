# 旋转固定集：动态位集与轨道前沿 DP

本批从 `fa7754485cb2f5a058e25f548d3c886f5774d808` 开始；该提交的上一批位运算优化已按用户要求先合并到主项目。本批新改动在隔离工作区开发和验证。

## 最终实现

`dynamic_bitset.rs` 提供任意长度 `Vec<u64>` 网格，按轨道翻转、跨字位移、整字连通扩散和 Euler popcount 判洞；行末与末行的空位防止跨行伪邻接及边界顶点截断。连通搜索复用缓冲区，触边计数增量维护。这个通用 Gray 内核没有 64/128 位尺寸限制；小尺寸仍保留 u64/u128 特化。

`symmetric_transfer.rs` 不再枚举每个完整对称子集。每步选择或排除一个完整旋转轨道，保留原格子的前沿连通标签、对角邻格占用、精确带符号 Euler 特征数和触边标志。具有相同后续行为的状态通过哈希表合并，其重数由 BigUint 累加。

只有四邻原格子边参与连通合并；不能把“属于同一旋转轨道”当作已经相连。对角占用仅用于真实 V−E+F 的共享顶点计算。离开前沿的分量若无法再与其他分量连接，立即丢弃；唯一分量封闭后只允许后续选择空轨道。最终只接受非空、四邻连通且紧包围盒匹配的状态。

自动路由在任一维度大于 7 且旋转轨道数大于 25 时选择 DP；其余情况保留低开销 Gray 路径。25 是算法选择阈值，不是输入尺寸上限。方形 n=8、9 的主要半转分支因此使用 DP，轨道较少的四分之一转仍使用 Gray。大尺寸的连通分区使用动态标签向量，几何位图使用动态字数组，计数使用任意精度整数。

`symmetry_probe WIDTH HEIGHT half|quarter` 是开发测量入口，可单独测某个矩形的固定集；它本身不施加资源限制，测试应由有界启动器调用。

## Astra high 调研与取舍

两路 GPT-6 Astra high 分别研究结构算法与剪枝/增量维护，另对冻结的实际 DP 代码及中心扫描增量进行只读审查。递归上限获准为四层，本次两路独立研究已覆盖所需范围，没有为增加层数而继续派发。

| 候选 | 本项目结论 | 本批处理 |
|---|---|---|
| 原格连通标签的轨道前沿 DP | 直接合并重复前缀，避开逐一访问全部 2^轨道数 候选 | 已采用，收益最大 |
| 动态多字位图 | 扩展位运算尺寸，降低通用几何内核常数开销 | 已采用，保留小字特化 |
| 中心行向外与永久孔洞吸收 | 数学上可行，须证明每个未处理格始终可沿空白背景通向外部 | 已实现并对照，因本机负收益未作为默认 |
| 商图＋奇偶位移/固定中心信息 | 有望压缩镜像重复的连通标签；普通商图连通性不足 | 后续优先研究方向，未实现 |
| 潜在图 S∪U 连通性、轨道割集、边界出口剪枝 | 可安全删除不可完成的搜索前缀；每状态 flood 也可能过贵 | 保留为后续候选，未盲目加入 |
| Gray 全动态连通性、每步更新全部 Euler 信息 | 仍遍历指数级候选；复杂更新可能贵于短位图 flood | 本批不采用 |
| 大规模并行、换 ZDD 库、通用树分解 | 不能自动减少必要状态；增加工程和验证成本 | 当前没有实测依据，暂缓 |

中心扫描候选与原 DP 计数一致，但本机 n=9 单次算法时间为 2.426348 秒、整进程 2.4583684 秒、峰值约 90.59 MiB；原顺序首轮约 1.90 秒/58 MiB，最终三次中位约 1.77 秒/58 MiB。n=8 中心扫描算法中位 0.665789 秒，也未胜过最终原顺序的 0.580403 秒。因此保留原顺序，候选源码和结果存为研究证据，不加入默认实现。这不是所有未来尺寸的普遍优劣证明。

重要正确性边界：

- 商图连通不保证原图连通。例如 3×3 只选顶行和底行，商图连通，原格图是两条分开的线。
- 洞采用背景四邻定义。`格子数−共边对数＋满2×2块数` 不是本项目需要的 Euler 公式；对角接触必须计入共享顶点。
- 任意轨道顺序下，前缀 χ≤0 不能直接吸收，因为后续可能填洞。最终默认实现保留精确有符号 χ。
- 中心向外的“行带顺序”与“方形半径顺序”不同，前沿宽度不能混为一谈。研究报告分别列出定义和几何宽度。

研究涉及的外部方法背景：[Kawahara 等的前沿搜索](https://www.jstage.jst.go.jp/article/transfun/E100.A/9/E100.A_1773/_article/-char/en)、[Jensen 的格动物转移矩阵枚举](https://arxiv.org/abs/cond-mat/0007239)、[电压图与提升空间](https://arxiv.org/abs/1411.4358)。本项目的中心扫描、商图相位简化等结论在 Astra 报告中单独给出推导，不假托文献已验证本实现。

- 最终 Release、Debug 各 80 项测试通过（主程序 64、对称探针 2、旧参考探针 7、CLI 7），没有忽略测试。
